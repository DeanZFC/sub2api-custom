# 共享账号池实现与验证记录

2026-09-09。本次没有部署生产环境，也没有上传真实账号凭证。

## 已实现

- 无管理员审核队列。上传先保存底层账号与归属，归属写入事务自动开放调度并发送调度缓存更新事件。
- 普通候选查询限定 system scope；共享分组通过不可变的 is_shared_pool 字段识别，不依赖可修改的分组名称。
- 共享入口检查平台开关并拒绝订阅计费。关闭后仍允许查看个人账号、暂停、删除和转入已有收益。
- 上传支持代理 URL、并发与倍率；有效并发为 floor(并发 × 并发倍率)，最少 1。售价倍率接入通用和 OpenAI 的文本/图片计费以及 OpenAI 视频计费；普通账号原有价格逻辑保持不变。
- 余额扣费与收益分账在同一数据库事务内执行，使用内部请求标识幂等；平台比例保存在每笔分账中。
- 收益默认等待 48 小时后释放，用户手动转入平台余额，不触发充值或邀请奖励。
- 卡片展示累计成功结算调用次数和脱敏最近调用。零费用的成功结算也计数；底层账号健康失败会从公开池移除，并在提供者卡片显示 invalid。
- 管理员设置支持共享池开关与抽成的读写。

## 验证

- PostgreSQL 16 临时容器、独立 schema：迁移重复执行、自动发布、暂停后在途请求结算、消费 100 / 抽成 10 / 收益 90、重复请求不重复记账、免费请求不增加收益、无归属时回滚消费。
- PostgreSQL 并发转余额：12 次相同幂等键请求只产生一笔转账，余额增加一次，收益解冻一次。
- 普通候选查询覆盖全局、平台、多平台、未分组及模型可用性查询的 scope 过滤。
- 服务测试覆盖免审核发布准备、有效并发、提供者售价倍率进入消费者实际扣费、普通账号不受该倍率影响。
- 网关中间件 unit 测试覆盖开关关闭、共享开启、普通分组不受影响、共享订阅拒绝。
- 前端类型检查与共享页面测试覆盖卡片展示和转余额重试。
- 代理记录带 owner_user_id，账号发布事务校验代理归属；上传自动启动 AccountTestService 健康检查，失败调用 SetError 并停止调度。
- HTTP 临时上游返回真实 JSON usage 后，使用生产 UsageBillingRepository 完成扣费、分账和卡片计数验收。

## 尚未覆盖的上线项

- 共享代理的用户名/密码使用 TOTP 配置的 AES-256-GCM 密钥密文保存，记录带 owner_user_id；未配置固定 TOTP 密钥时拒绝创建共享代理，避免重启后无法解密。
- 当前自动健康检查在上传后执行一次；周期性重试、失败阈值和管理员冲正界面仍需单独建设。
- 尚未对真实第三方账号做生产凭证验收；端到端测试使用本地 HTTP 上游，避免发送真实凭证。
- 对所有特殊多模态、独立附加计费和分组 fallback 路径的共享准入/分账仍需补充专项审计。
- 当前服务包带 unit 标签编译仍受已有 gateway_usage_billing_fallback_test.go 的旧参数列表影响；普通构建和共享定向测试通过。

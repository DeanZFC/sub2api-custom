# Excel / BPS 授权与连接诊断

## 开启协议

在「系统设置 → 功能」的 **Excel / BPS** 卡片开启全站协议，然后在账号编辑中开启该账号的 Excel / BPS，并选择适用模型。全站开关兼容已有安装，未配置时默认为开启；新账号的 BPS 仍默认关闭。Free 套餐不能开启 BPS。

全站开关独立保存，关闭后所有 BPS 请求均受限制。普通 Codex 账号仍可使用原生通道；以 Excel OAuth 为主凭据的账号不能将 Excel Token 用于原生 Codex。

## 手动创建 Excel OAuth 账号

在「账号 → 添加账号 → OpenAI」选择 **Excel OAuth**，配置账号名称、代理及 BPS 模型范围，再进入授权步骤。

- 生成的授权链接使用独立 Excel OAuth 客户端。登录后将带有 `code` 和 `state` 的完整回调 URL 粘贴到输入框。
- 也可提交对应 Excel 客户端的 Refresh Token。普通 Codex 或 Mobile Refresh Token 不能当作 Excel Token 使用。
- 该模式隐藏 Codex 会话、PAT、Agent Identity 等导入入口，避免混用授权资料。
- Excel OAuth 账号重新授权时会继续使用 Excel 客户端。手动授权流程不依赖自动授权 Worker。

## 为现有 Codex 账号取得独立 BPS 授权

在账号编辑或「账号连接测试」中展开 **BPS 独立授权与授权材料**：

1. 查看授权服务状态。自动授权需要授权 Worker 可用。
2. 如尚未配置凭据加密，点击「初始化凭据加密」。
3. 填写登录邮箱、登录密码和 TOTP 密钥，选择授权代理。
4. 保存授权材料后点击「开始 BPS 授权」，查看任务状态。展开期间只对进行中的任务轮询。

代理来源支持跟随账号代理、指定托管代理 ID、Mihomo。账号未配置代理时，「跟随账号代理」沿用该账号的直连行为。授权代理与会话请求的 BPS 代理选项是分别配置的。

界面只显示密码/TOTP 是否已配置，不回显保存值。输入框留空保留已保存内容；勾选清除项才删除对应材料。保存成功、关闭面板、切换账号或关闭弹窗时会清空本次输入。

现有 Codex 账号取得的是独立 Excel 授权，不会用 Excel Token 覆盖 Codex 主凭据。授权失败或需要上游安全验证时，查看面板状态和错误代码并修正授权材料；账号停用或暂停不会因授权恢复而自动启用。

## 连接测试与错误定位

模型列表读取失败会显示原因，并提供「重新加载模型」。授权进行中、缺少材料、授权失败或上游安全验证阻塞会分别提示。

「测试请求已开始」仅表示请求已发出。只有实际收到 BPS 上游响应时，诊断卡片才显示 HTTP 状态、模型、Request ID 和安全错误代码。随后测试失败仍保留这些证据；DNS、代理、网络等传输失败不会凭空生成上游 HTTP 状态。

遇到 `basispoints_upstream_error` 时，优先记录同一次测试的 HTTP 状态、Request ID 和错误代码，再核对独立 Excel 授权状态、模型权限和代理路径。该错误本身不能证明是账号、代理或模型权限中的哪一项导致。

BPS 账号还提供 **BPS 文本与工具往返验证** 模式：依次验证随机文本、一个无外部副作用的 echo 工具调用、工具结果后的文本。正常完成需要三次上游请求；任何阶段失败都会停止。此模式只接受真实 BPS 路由，不能借原生 Codex 或 VM 通道返回成功。同一账号同时最多一个探测，同一服务实例最多三个。

## 403 自动恢复

在账号 BPS 设置中先开启「403 自动关闭」，再按需开启「403 自动恢复」，配置 1–10080 分钟的检查间隔，默认 60 分钟。

403 自动关闭后，编辑账号仍保留模型范围及恢复配置。后台恢复探测成功后才能恢复 BPS；账号本身停用或暂停状态仍由管理员决定。普通手动关闭和批量关闭不会被当成新的 403 恢复任务。

## 本次验证边界

本次集成通过模拟上游与组件测试验证路由、诊断证据、授权资料处理和界面接线；未使用真实账号登录或向真实 BPS 上游发起探测。部署后可用一个已有授权的测试账号验证实际连通性。

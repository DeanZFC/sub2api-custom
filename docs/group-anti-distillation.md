# 分组零缓存保护已移除

分组里的零缓存保护已经退役，不再提供配置入口、管理 API、HTTP / WebSocket 请求拦截、采样或邮件通知。旧 Redis 暂停状态不再生效，按原 TTL 自然过期；迁移 `342_retire_group_zero_cache.sql` 清理旧分组配置。

请使用账号列表「最近使用」指标区域中的新规则，可配置成功率、缓存率、平均首字和平均耗时的暂停、恢复条件。自动恢复采用冷却后少量放行试运行、各项指标在新样本上达标后恢复的方式。规则默认关闭，不会将原分组客户级规则自动转换成账号级规则。

配置和运行边界见 [账号请求指标规则](account-performance-monitor.md)。

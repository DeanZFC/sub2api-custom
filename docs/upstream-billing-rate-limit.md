# 账号上游倍率上限

在创建或编辑 API Key 账号时，可在「自动检测上游倍率」附近填写「上游倍率上限」。留空表示不限制；`0` 表示只允许已检测到的免费倍率。

- 配置上限后，该账号强制启用自动检测。全局自动检测关闭时，这类账号仍按检测周期运行；清空上限后才允许关闭账号检测。
- 使用上游当前生效倍率比较，包含高峰时段系数。超过上限时，停止给该账号分配新请求；等于或低于上限时解除倍率限制。
- 不改动账号的手动调度开关和启用状态，手动停用的账号不会因倍率恢复被自动启用。已在执行的请求不主动中断。
- 自动同步账号计费倍率仍是独立选项，配置上限不会自动开启该选项，也不改变用户或分组收费配置。
- 检测失败时继续依据上次成功取得的数据判断，不会因为失败或数据过期自动清除超限限制。已知高峰时段切换仍按上次返回的时间规则计算。
- 尚未取得有效倍率时不额外阻断调度。该功能依赖上游支持现有 `/v1/sub2api/billing` 接口；不支持此接口的上游无法通过此功能判断倍率。

检测沿用现有间隔（默认 30 分钟），后台每分钟处理到期账号。修改上限会立即对已有检测结果生效；也可手动检测获取最新结果。

管理 API 使用 `extra.upstream_billing_rate_limit` 保存有限非负数，传 `null` 清空。`upstream_billing_rate_limited` 表示当前倍率限制是否生效；`schedulable` 仍表示管理员控制的调度开关。

上限和探测结果复用账号 JSON 配置，不需要新增数据库迁移。探测写回及配置更新会同步调度缓存。

# 渠道质量自动保护

在 **渠道质量管理 → 新建/编辑检测规则 → 自动质量保护** 中开启，默认关闭。
选择“指定账号”或“所有账号”，然后为已选择的检测类型分别配置保护规则。
分组汇总测试不直接暂停账号，以免用整个分组的指标误判某个账号。

## 判断条件

- 一小时统计：成功率、缓存率用百分比（例如 `80` 表示 80%），首字延迟用毫秒。
- 普通测试：可按测试耗时设置阈值；数字测试还可按输出数字设置阈值。
- 阈值支持严格“小于”和“大于”，等于阈值不触发。任一条件触发就暂停。
- 可配置最低样本数。没有数据或有效样本不足时保持待评估，不按零计算，也不解除已有暂停。
- 可开启“检测执行失败时暂停”。定时测试仍先按现有策略额外重试三次，最终失败才作判断。
- 答案可用完整匹配、包含匹配、数值匹配。图形是否画对不能可靠地用 HTML 字符串判断，鹈鹕等图形测试建议使用投票。

## 用户投票

为测试开启投票后，配置“超过多少张不通过票暂停”和“至少多少张通过票恢复”。
例如不通过门槛填 `2`，第三张不通过票触发暂停；恢复门槛填 `3`，至少三张通过票且没有其他异常时可以恢复。
启用投票时，“参考答案”展示给用户参考，不再作为程序字符串判定条件。

用户在渠道质量检测页的独立投票区查看新结果并投通过/不通过。每个用户每轮一票，允许改投。
只有有权查看该分组的已登录用户可以投票，接口只公开账号 ID。
投票不通过门槛优先于通过票数，且通过票不能覆盖指标异常。

每次重新执行该账号的对应检测，生成新一轮投票，之前的票数不累加；旧结果不能继续投票。
没有有效结果或测试执行失败时不开放投票。

## 自动暂停与手动停用

检测触发暂停后，账号状态显示 **检测自动暂停**，并显示原因。
普通请求不再调度该账号，管理员的“调度”开关仍保留原值。

定时账号检测仅选取未删除、调度开关开启、且状态为“正常”或“检测自动暂停”的账号。
在账号排队等待期间关闭调度，也会在调用上游前再次检查。
手动关闭调度的账号不参与复测，不会被自动打开。

下一轮指标/答案检测通过后可解除对应暂停；依赖投票的检测需要新一轮通过票达到门槛。
同一账号存在多个检测规则时，所有暂停原因均解除后才恢复。
自动恢复只处理检测造成的暂停，不覆盖其他错误状态或手动停用。

正常结果列表继续隐藏自动暂停账号；独立投票区可展示其新结果，供用户重新判定。
后台 OAuth 凭据续期继续运行，避免因检测暂停而失去复测能力。

禁用、删除检测规则或修改保护条件，会清理该规则的旧判定与投票资格。
如果没有其他暂停原因且调度仍开启，可恢复该规则暂停的账号；仅修改名称或执行时间不会重置判定。

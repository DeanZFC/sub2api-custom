# 统一上游错误提示

在管理员后台的「系统设置 → 网关 → 统一上游错误提示」填写对用户显示的文案，例如：

> 本次请求未能完成，请稍后重试。

保存后，新请求的上游错误会使用这段提示。最多 500 个字符，首尾空白自动去除；留空恢复默认错误处理。现有 WebSocket 连接使用建立连接时的设置，重新连接后使用新设置。

覆盖 OpenAI、Claude、Gemini、Grok 等网关的 HTTP 错误、HTTP 200 内的协议错误、SSE 和 WebSocket 错误，包括上游的参数、上下文、策略、额度和服务异常。统一提示优先于错误透传规则的原文或自定义文案。异步图片任务、批量图片失败列表及导出错误、普通用户的错误请求详情也使用统一提示。

只替换面向用户的错误展示。HTTP 状态码、必要的协议错误码和流式终止结构继续保留；正常回答、重试、账号切换、用量和计费判断仍使用原有逻辑。站内登录、权限、余额和订阅等本地错误保留具体说明。

原始上游原因与详情仍保存在管理员的「调用错误」中，异步图片任务也会独立记录。用户端的历史任务查询与错误详情只返回展示副本，不回写已保存的记录；普通用户的错误详情会隐藏包含原文的响应正文。日志是否记录仍遵循现有监控开关和过滤规则。

配置存储在现有 settings 表的 `upstream_error_message` 键，无需数据库迁移。单实例保存后立即更新缓存，多实例在缓存刷新后生效（最长 60 秒）。

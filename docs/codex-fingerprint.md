# Codex 指纹收敛

本次整理以已合入的官方提交 `49a39b6dc1abed30fd227611e8af1108bc427610` 为基线。官方 Codex ticket 功能保持独立。

## 配置入口

账号管理 → 新建或编辑 OpenAI OAuth 账号 → Codex 指纹收敛。批量编辑也支持。新建账号表单默认选择单机多窗口，可手动关闭；删除了会隐式启用指纹的 `gateway.openai_account_unique_fingerprint_enabled` 全局配置。

| 模式 | 来源 | 行为 |
| --- | --- | --- |
| 关闭 | 官方 | 保留客户端身份 |
| 设备收敛 | 官方 | 只统一账号设备身份 |
| 会话收敛 | 官方 | 统一设备和会话，按客户端会话派生线程 |
| 完全收敛 | 官方 | 统一设备、会话和线程 |
| 单机多窗口 | 唯一自定义模式 | 稳定设备、三个根窗口及窗口忙时的子智能体身份；保留各会话缓存键 |

单机多窗口整合了账号稳定种子、HTTP 请求头与请求体身份一致性、WebSocket 握手身份、内置 Mac Codex TLS，以及智能测试请求的同源身份。切换账号时清理旧身份，改变 TLS 身份后不复用旧 WebSocket。窗口数只决定身份映射，**不限制请求并发**。

如果启用了另外的 OAuth 转发插件，插件仍负责自身网络传输；这里的内置 TLS 指纹仅作用于本程序直接发起的上游连接。

## 删除与合并清单

| 原有自定义功能 | 处理 |
| --- | --- |
| Prism 通道、认证、Cookie、模型与请求适配 | 删除后端、前端、路由、测试和专用文档，升级时清除旧配置与专用凭据 |
| 独立账号保护策略、mode1 等模式及配置接口 | 删除；原已启用的 OpenAI 身份保护迁移至单机多窗口 |
| 自适应并发、保护模式的并发上限 | 删除；使用账号正常配置的并发 |
| 账号健康自动隔离、解封及专用设置 | 删除；保留官方限流、过载和其他正常调度状态 |
| 保护模式强制固定代理与完整性拦截 | 删除；代理按账号现有正常配置工作 |
| 稳定设备身份、TLS、测试与真实转发一致性 | 合并到 Codex 指纹 |
| 额外的“账号唯一设备”模式 | 合并为官方设备收敛，升级时保留原设备种子 |
| 429 无恢复时间时跳过冷却 | 还原官方配置逻辑；默认启用 5 秒回避，尊重后台设置；Spark 分支也恢复官方行为 |

## 升级迁移

迁移 `254_retire_prism_and_account_protection.sql` 会清理旧字段和 `account_health_settings`。旧保护有有效快照时，还原原 TLS/代理设置；仅当当前并发仍等于保护程序施加的值时还原原并发，保留之后的手动修改。缺失或损坏的快照不会被猜测为某个并发值。

只清理 `health:` 前缀的临时隔离，不清理官方 429、过载或其他来源的调度封锁。OAuth 凭据、Codex ticket、代理池和其他业务字段保留。只使用 Prism Cookie 的旧账号失去该通道能力，需要正常 OAuth/API 凭据才能继续使用。

已有显式单机模式继续生效；存量未配置模式的账号仍按官方默认关闭；通过新建账号表单创建时默认写入单机多窗口。

## 验证范围

覆盖指纹身份稳定与关闭、HTTP/WS 与测试请求一致性、WebSocket 复用切换、账号并发值不被改写、官方 429 回避和 Codex ticket 回归；迁移在临时 PostgreSQL 中验证恢复、保留手动修改、精确清理和重复执行。前端账号表单测试、语言包检查及生产构建通过。未连接生产环境或验证上游服务实况。

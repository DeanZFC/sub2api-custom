# Codex 指纹收敛

指纹、兼容请求缓存键和直连 TLS 行为对齐官方 Sub2API d851a384。新建账号默认关闭指纹收敛。

| 模式 | 行为 |
| --- | --- |
| 关闭 | 使用官方默认身份处理 |
| 设备收敛 | 统一账号设备身份 |
| 会话收敛 | 统一设备和会话，按客户端会话派生线程 |
| 完全收敛 | 统一设备、会话和线程 |

入口：账号管理 → 新建或编辑 OpenAI OAuth 账号 → Codex 指纹收敛；批量编辑支持相同的四种官方模式。服务端管理稳定种子，不接受客户端覆盖。

官方会话粘性、previous_response_id 归属和缓存键派生与所选指纹模式共同工作。WebSocket 握手及直连使用官方指纹/TLS 实现；多代理池继续按代理隔离连接，VM 路由在配置变更时清理对应连接池。

# 渠道质量管理：配置体验重设计

## 设计目标

日常只需选择分组、填写四个质量目标，再配置智力检测项目与时间。异常暂停、冷却和主动复测恢复由系统执行；采样和预算放到详情或更多设置。所有说明以实际后端行为为准。

## 信息架构

- 分组质量：默认入口，每组一个目标，查看实际指标、暂停原因和恢复状态。
- 智力检测：选择糖果、鹈鹕等检测项目及执行计划，查看每轮结果。
- 事件与恢复：沿用被动保护的状态与事件记录，并明确主动检测的历史入口。
- 更多设置：检测类型与题库、检测预算与供应商、健康总览；旧规则及评分深链接返回分组质量。

## 分组质量与自动恢复

1. 选择分组。新目标默认缓存率 ≥80%、可用率 ≥90%、TPS ≥30 token/s、首字 P90 ≤15 秒；已有自定义阈值和禁用指标不覆盖。
2. 启用自动保护。按账号和模型统计滚动最近 1 小时全部真实请求，每项至少 20 个有效样本，连续两次异常且每次至少 5 个新样本；可用率异常持续 60 秒、性能异常持续 300 秒后确认暂停；等于目标值不算异常。
3. 暂停后冷却 5 分钟，由系统定向请求同一账号和模型主动验证；至少两批且健康证据覆盖 120 秒，每批每项至少 5 个有效样本，缓存率 ≥85%、可用率 ≥95%、TPS ≥36、首字 P90 ≤12 秒。冷却到期不会直接恢复。
4. 所有分组目标统一主动恢复。受保护账号模型不会接到客户试运行请求，也不能通过应急兜底绕过暂停；没有健康供给时返回不可用。正常 API Key 备用分组是独立路由功能，只能使用通过全部准入的健康账号。

旧自定义实时流量规则已移除；分组质量目标的客户恢复试运行、可用性优先模式及全组应急兜底也已移除。独立统计类定时检测仍保留其账号级暂停、连接探测和限量试运行机制。界面只展示四项指标、暂停原因、主动恢复证据和账号排除；共享检测预算仍在更多设置管理。整体指标达标但仍有账号暂停或主动复测时显示“保护中”，不会误示全组已恢复。


## 定时能力检测与成本

保留现有检测引擎和判断条件。基础设置突出检测项目、范围、排除账号、模型、执行计划；排除账号在选择分组后直接显示，可按名称或 ID 搜索并勾选。显示排序直接编辑，保留数量等归入高级设置。新建计划默认开启“全部自动检测通过”：本轮明确失败就暂停，下一轮所有必需项通过后恢复，本模式不再单独配置历史通过率门槛。可关闭自动化只记录结果；旧单项、组合模式及复杂改组动作保留在高级设置。

渠道质量检测页面按账号展示结果，在页面顶部统一切换模型，所有账号的检测项和统计同步更新；全页只保留一个切换入口，默认使用配置顺序中的第一个可用模型。展示遵循以下语义：

- 执行完成与质量结论分开判断：成功返回输出只说明执行完成，卡片按明确质量证据显示通过、不通过或待判定；没有质量结论时不标记通过。
- 主动检测卡直接显示统计范围、配置次数、通过次数与通过率，例如“7 天内最近 10 次 · 通过 8 次 · 80%”；样本未满时常显“已采集 6/10 次”。不足一天的窗口使用准确的小时或分钟单位。详情只保留额外证据和恢复规则；没有统计或通过率未知时分别显示暂无统计或“—”。
- 鹈鹕等 HTML 检测卡单独放在右侧预览列，普通检测卡在左侧按配置顺序纵向排列，避免高预览把短卡下方撑出空白；没有 HTML 时保持单列紧凑排列，窄屏统一改为单列。各类卡片使用统一页脚放置统计、检测时间、历史入口及放大入口，长内容保持在卡片内。
- 管理员已判定的结果直接显示结论，将修改操作折叠到“修改判定”；待判定结果保留直接处理入口。
- 通过使用绿色，不通过或暂停使用红色，待判定、样本收集中及证据过期使用黄色，未知与说明使用中性色；统计窗口已满只表示样本齐全，不宣告账号健康。

结果展示本身不改写已有计划的自动化开关或调度动作；新计划默认行为及最新轮恢复由保护配置控制。

预算和健康降频只在启用后展开相关参数；全局请求上限优先展示，账号额度、Token 预占归入高级额度。供应商聚合为可选设置。

## 必须保留的语义

- 无数据、遥测缺失、样本不足都不代表健康，不自动放行。
- 分组目标暂停后：冷却、系统主动复测、全部启用指标达到恢复条件才解除本目标限制。冷却结束和证据过期均不代表恢复。
- 人工停用、其他策略和账号自身限制仍独立生效。
- 已有分组目标阈值、题库和历史结果保留；调整策略造成的证据重置继续提示。
- 历史迁移保留，当前升级归档并移除独立评分配置，保护阈值、检测结果、共享流量证据及历史事件保留。单项/组合模式的历史门槛保持原样。
- 本地实现和数据库迁移测试不代表已发布或部署到生产。

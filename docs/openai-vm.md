# VM Bridge 退休与旧绑定恢复

VM Bridge 的服务端传输、控制接口、前端入口和独立部署代码已移除。新版本只保留旧绑定的隔离保护，不提供 VM 转发能力。

迁移 353 会将仍有 VM 绑定或退休标记的账号及影子设为停用、不可调度，保留原始绑定、配置和迁移前状态审计。未绑定的普通账号不改变路由或状态。旧管理数据不会自动删除，外部槽位和容器也不会由数据库迁移删除。

升级前应在旧版本中停用母账号与全部影子，等待在途请求结束，通过旧版本解绑入口回收外部槽位并恢复原代理。确认不存在 VM 绑定后再升级。

已经升级且仍有旧绑定时，先保留数据库备份和外部状态。使用与历史迁移兼容的旧版本，在维护窗口完成解绑、核实原代理恢复；然后在停用且不可调度状态下显式清除退休标记，最后另行启用账号。不得直接删绑定表、清标记或把代理设为直连来绕过恢复过程。迁移 353 不要求删除历史迁移，也不应修改历史迁移校验和。

本次代码调整未连接服务器，没有停止或删除任何已部署容器、镜像、槽位或数据卷。外部资源清理需在实际部署环境核实后单独执行。

# 账号请求指标规则

在管理员账号列表中，点击「最近请求」里的任一指标即可配置账号，即使账号还没有请求记录。列表显示最近 1 小时的指标。已启用规则的账号默认打开「运行状态」，可查看本轮实际样本、试运行恢复目标和最近事件。规则关闭时默认打开「规则设置」。切换视图和刷新状态都会保留未保存的设置。

## 统计与阈值

列表统计最近 1 小时全部日志，不受下方 10 条请求展示限制。所有实例读取同一数据库，并与规则评估复用同一聚合查询。

- 成功率：已记录成功请求 /（成功 + 失败）。按账号、API Key 和请求 ID 去重；终态失败覆盖同请求的部分输出。免费但有 Token 的成功请求计入，空的失败占位 usage 不计入成功。WS 连接错误单独计失败，不抹去已完成的 WS 轮次。
- 缓存率：成功流式 / WS 请求的缓存读取 Token / 文本提示 Token；排除图片输入，按 Token 加权。
- 平均首字：成功流式 / WS 请求的有效首字时间。
- 平均耗时：成功请求的有效总耗时。

排除赛博计费记录和错误日志中的 count_tokens；没有账号归属的错误不分摊给账号。统计依赖持久化日志，未写入日志的结果未知。缺失或负数耗时、缺失缓存数据不参与该指标；无样本为 `null`，真实零值有效。运维监控关闭时停止规则评估，配置弹窗显示指标未知，不能启用新规则；仍允许关闭或手动解除已有规则。

规则默认关闭。常用配置只需填写最低成功率、最低缓存率、最高平均首字或最高平均耗时。打开「更多阈值」可设置另一侧边界和独立恢复范围。留空的暂停阈值不参与评估。百分数使用 0–100，耗时使用毫秒。每 30 秒评估一次，任一已配置指标的样本达到设置值（默认 20）且严格越界即暂停，等于阈值不触发。

## 自动恢复

默认勾选自动恢复，但仅在启用规则后生效：

1. 暂停后冷却（默认 5 分钟，可配置 1–1440 分钟）。
2. 冷却到期后的评估开启 10 分钟试运行。有多个合格账号时，未绑定的新业务请求优先尝试已到放行时间的试运行账号。多个账号同时等待时，先尝试等待最久的。分组、模型、严格故障转移层级、利润和并发条件仍然适用，已有的有效会话绑定仍然优先。每个试运行账号每 5 秒最多放行一个请求，每轮最多放行恢复样本数的 3 倍。
3. 只检查本轮开始后的新样本。全部选中指标都达到恢复样本数（默认 3，可配置 1–100），且都在恢复上下限内，才解除暂停。
4. 任一指标达到恢复样本数后越过暂停阈值，立即在该次评估重新暂停。到期评估使用本轮开始至截止前的样本，即使评估稍后执行也能恢复。到期仍未恢复时，事件会记录「有效样本不足」或「指标未达恢复范围」，然后进入下一轮冷却。

恢复阈值留空时沿用对应暂停阈值，也可以设置更严格的恢复条件，避免反复启停。没有流量、指标样本不足、旧样本过期都不算恢复。选择缓存率或首字条件时，必须有足够流式 / WS 请求产生对应指标。

试运行和恢复后的规则评估从本轮开始计数，最多回看 1 小时；弹窗显示实际参与评估的样本。列表仍显示完整最近 1 小时，旧失败因此可能仍显示在列表，但不会立即把刚恢复账号再次暂停。

「已放行」统计通过最终转发准入的次数。网关先选定账号、取得并发槽并通过利润检查，再由数据库原子领取名额。候选复查、排队和抢槽失败都不会消耗名额。多个实例争用同一名额时仅一个能通过。WebSocket 两种接入模式按请求轮次检查，Live 在取得通话租约后检查。批量图片任务在首次提交给上游时计一次，后续轮询和结算沿用原账号。

「恢复样本」按每项指标单独统计。例如已放行 3 次，其中只有 1 个成功流式请求带有效首字耗时，则平均首字的恢复样本为 1。已放行为 0 时，应查看是否有符合该账号条件并实际选中它的业务流量。已放行但样本不足时，应核对请求类型、结果及对应指标的日志。

## 状态归属与升级

只修改独立规则表，不改管理员手动调度开关、账号状态、限流或其他暂停原因。在途请求继续执行。保存配置会清除此规则的暂停并重新评估；手动解除会同时关闭规则。自动恢复只解除本规则自身的暂停，管理员禁用的账号不会被自动启用。

本次重构直接使用现有 V2 配置、暂停状态和事件记录，无需迁移或重新设置阈值。仅从早于 V2 的版本升级时，历史迁移 `341_account_metric_rules.sql` 会退役旧 HTTP 规则并保留历史事件，`342_retire_group_zero_cache.sql` 会清理旧的分组零缓存配置。

管理员 API 保留 `/accounts/performance` 批量读取、`/:id/performance` 保存、`/:id/performance/release` 解除及 `/:id/performance/events` 审计路径。批量读取默认返回评估指标，列表可传 `include_metrics: false` 仅加载状态。`phase` 表示关闭、监测、暂停或试运行，`recover_after`、`trial_ends_at` 和 `trial_limit` 在对应阶段提供时间和名额。原有 V2 配置继续生效。保存校验 revision，解除还校验 pause_generation。配置、暂停、试运行、恢复和解除均在事务内写入事件，多实例评估使用行锁。
